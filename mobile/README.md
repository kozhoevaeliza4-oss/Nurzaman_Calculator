# Асыл-Аманат — мобильное приложение

Нативное приложение (React Native + Expo) для той же системы управления
детским садом — использует тот же backend, что и веб-версия
(`kms/`), без изменений на сервере.

## Что внутри

- **Все 6 ролей**: директор, администратор, бухгалтер, воспитатель,
  медработник, родитель — тот же ролевой доступ, что и в вебе.
- **Родитель**: личный кабинет (баланс, меню, посещаемость, документы,
  уведомления) + чат с AI-ассистентом.
- **Персонал**: обзор (сводка, группы, дети, родители, сотрудники),
  меню, расходы, отчёты (с выгрузкой CSV через системное меню "Поделиться"),
  рассылка уведомлений.
- **Карточка ребёнка**: начисления/оплаты, посещаемость, документы
  (загрузка/скачивание/удаление).
- **QR-сканер через камеру** — отметка посещаемости сканированием
  настоящей камерой телефона (`expo-camera`), а не только кнопкой, как
  в вебе.

## Запуск для разработки

```bash
cd mobile
npm install
npx expo start
```

Откройте в приложении **Expo Go** (iOS/Android) отсканировав QR-код в
терминале — весь код на JS, без нативной пересборки для разработки.

По умолчанию приложение обращается к боевому серверу
`https://asyl-amanat-kms.onrender.com` (см. `src/api.ts`, константа
`API_BASE_URL`). Чтобы работать с локальным backend — поменяйте это
значение на адрес вашей машины в локальной сети (например
`http://192.168.1.50:3000`), `localhost` с телефона не сработает.

## Сборка для публикации (App Store / Google Play)

Через **EAS Build** (облачная сборка Expo, не требует Mac для iOS):

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build --platform android   # .aab для Google Play
eas build --platform ios       # .ipa для App Store (нужен Apple Developer)
```

Публикация:

```bash
eas submit --platform android
eas submit --platform ios
```
