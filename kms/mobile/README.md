# Асыл-Аманат — мобильное приложение

React Native (Expo) приложение для iOS и Android, использующее тот же API,
что и веб-панель (`kms/frontend`) и бэкенд (`kms/src`). Один код — оба
приложения (родительское и для персонала), роль определяется автоматически
после входа.

## Что внутри

- **Вход** — тот же `/auth/login`, что и на сайте.
- **Родитель**: личный кабинет (баланс, посещаемость, меню, документы,
  уведомления по каждому ребёнку) + чат с AI-ассистентом.
- **Персонал** (директор/админ/бухгалтер/воспитатель/медработник): сводка
  за месяц, список групп и детей, карточка ребёнка с начислениями,
  оплатами, отметкой посещаемости и документами.
- Профиль с выходом из аккаунта для всех ролей.

Не перенесено в мобильное приложение (пока доступно только в вебе):
управление меню на неделю, расходы, отчёты с CSV-экспортом, рассылка
уведомлений, формы создания групп/детей/родителей/сотрудников. Это
осознанное сокращение объёма первой версии — при необходимости добавляется
по тому же образцу, что и остальные экраны.

## Запуск для разработки

```bash
cd kms/mobile
npm install
npx expo start          # затем откройте в Expo Go на телефоне (отсканировав QR-код)
npx expo start --web    # быстрый предпросмотр логики в браузере (не финальный UI на native)
```

По умолчанию приложение обращается к `https://asyl-amanat-kms.onrender.com`.
Чтобы указать другой сервер (например, локальный бэкенд при разработке):

```bash
EXPO_PUBLIC_API_URL=http://localhost:3000 npx expo start
```

## Публикация в App Store и Google Play

Сборка идёт через облачный сервис Expo (EAS) — Mac не нужен даже для iOS.

1. Создайте аккаунт на [expo.dev](https://expo.dev) (бесплатно) и войдите:
   ```bash
   npx eas login
   ```
2. Свяжите проект с вашим аккаунтом Expo (один раз):
   ```bash
   npx eas init
   ```
3. Соберите приложение для обеих платформ:
   ```bash
   npx eas build --platform all --profile production
   ```
   Сборка идёт на серверах Expo, готовые файлы (`.ipa` для iOS, `.aab`
   для Android) будут доступны по ссылке в терминале и в личном кабинете
   expo.dev.
4. Публикация в сторы:
   ```bash
   npx eas submit --platform ios
   npx eas submit --platform android
   ```
   Для этого шага нужны:
   - **Apple**: аккаунт Apple Developer Program ($99/год) —
     [developer.apple.com](https://developer.apple.com)
   - **Google**: аккаунт Google Play Console ($25 разово) —
     [play.google.com/console](https://play.google.com/console)

   `eas submit` попросит войти в эти аккаунты и сам загрузит сборку.
   После загрузки Apple и Google проводят модерацию (обычно 1–3 дня у
   Apple, от пары часов до суток у Google).

5. Идентификаторы приложения уже заданы в `app.json`:
   `kg.asylamanat.kms` (iOS bundle ID и Android package). Изменить их
   можно там же, но после первой публикации менять нельзя.

## Иконка и брендинг

Иконки (`assets/icon.png`, `assets/android-icon-*.png`,
`assets/splash-icon.png`) сгенерированы из фирменного логотипа сада. Чтобы
заменить — положите новые файлы того же имени и размера и пересоберите.
